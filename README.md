# Software Cost Estimation

A machine learning project for estimating software development effort and cost using software project datasets.

## Project Structure

- `backend/` — API and model-serving components
- `frontend/` — Web interface
- `data/` — Raw and processed datasets
- `models/` — Trained model artifacts
- `notebooks/` — Data preprocessing, model development, and evaluation
- `docs/` — Project documentation and reports
- `.github/workflows/` — Automated weekly report workflow
- `generate_report.py` — Generates project progress reports
- `requirements.txt` — Python dependencies

## Technologies

- Python
- Machine learning and data analysis
- FastAPI
- React
- SHAP and LIME for model explainability

Install the Python dependencies:

```bash
pip install -r requirements.txt
```

For backend and frontend setup instructions, see the respective README files in `backend/` and `frontend/`, where available.
